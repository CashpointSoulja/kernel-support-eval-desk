# Jobs to be done

## Support specialist

When a business identity question arrives, I want a draft tied to exact source passages, so I can verify it, edit it, or hand it to a person without guessing.

**Success in this concept:** I can see the route, matched keywords, confidence label, retrieval scores, source identifiers, and draft before adding the ticket to review.

## Data-quality reviewer

When a hierarchy or merge issue arrives, I want the reported and expected behavior captured at the right entity level, so the correction is clear and similar reports can be noticed.

**Success in this concept:** I can record the expected behavior, choose brand, subsidiary, parent, or branch, add a synthetic evidence link, and record two identifiers that must remain separate. Similarity is a token-overlap hint and never merges cases automatically.

## Quality owner

When a correction is approved, I want a portable fixture, so later rule changes can be checked against the agreed route, refusal, citations, and separation constraint.

**Success in this concept:** An approved queue item can be downloaded as JSON and run alongside the seeded fixtures. Unapproved items cannot be exported.
