# V2 roadmap

This is a possible sequence, not a delivery commitment.

## 1. Make current evidence easier to inspect

- Weight title and passage terms separately.
- Highlight matching words in each retrieved passage.
- Store a corpus version in every exported fixture.
- Explain the fixed retrieval threshold beside each score.

## 2. Strengthen review records

- Require a reason for rejection and escalation.
- Preserve the original draft beside reviewer edits.
- Confirm the exact fixture contents before download.
- Prevent duplicate reports from being added on every review action.

## 3. Make fixture results more useful

- Validate fixture structure before execution.
- Import reviewed fixture files into the browser.
- Group failures by route, refusal, citation, and separation.
- Check citation relevance, not only identifier existence.

## 4. Prepare for a controlled pilot

- Define ownership for documentation, routing rules, and fixture review.
- Agree on access, retention, deletion, and audit requirements.
- Add shared storage and permissions only after privacy and security review.
- Establish baseline route agreement, refusal agreement, review time, and repeat issue coverage.
