# Viability

## Product wedge

Business identity support has repeatable questions about brands, subsidiaries, parents, branches, merges, identifiers, and data processing. A small documented set of rules can help prepare consistent replies. Ambiguous, account-specific, billing, and contract cases can be handed to a person.

The useful wedge is not unattended support. It is a reviewable bridge from a support issue to a reusable regression fixture.

## What the concept demonstrates

- A route can expose the exact keyword signals that caused it.
- A draft can be limited to retrieved source passages and their identifiers.
- Missing evidence can cause a visible refusal.
- A reviewer can edit the reply and control whether a fixture is exported.
- A fixture can preserve route, refusal, citation, and separation expectations.
- A local audit history can make the path inspectable during a demo.

## What remains unproven

- Whether the keyword rules classify a representative support queue accurately.
- Whether token overlap retrieves the most useful passage for varied customer language.
- Whether cited drafts reduce handling time without increasing review effort.
- Whether reviewers agree on expected behavior and produce reliable fixtures.
- Whether the fixtures catch meaningful product or data regressions.
- Whether teams will maintain the corpus, rules, and fixture set.

## Validation path

1. Create an approved, de-identified test set with representative routes and refusal cases.
2. Compare suggested routes and refusals with independent reviewer decisions.
3. Review citation relevance, not just citation existence.
4. Observe time to prepare, review, and preserve a case against the current workflow.
5. Run approved fixtures against planned rule changes and classify the failures they catch.
6. Decide whether the evidence supports a limited, access-controlled pilot.

Any real deployment would require integration design, security and privacy review, access controls, retention and deletion rules, monitoring, and named owners for sources and fixtures.
