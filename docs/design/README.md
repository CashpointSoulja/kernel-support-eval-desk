# Design reference

This directory contains the written Kernel marketing design inventory and a self-contained visual brand sheet for a future support-desk restyle; open `visual-guide.html` directly in any desktop or mobile browser (no server or network connection is required), and use the canonical custom properties in `../../design/tokens.css` when implementing the documented system.

## Applied in the app

The app now applies the canonical tokens directly: off-white provides the page canvas; white, pastel green, and primary tints define cards, badges, and selected surfaces; primary green defines actions, focus rings, and pass states; pastel and mid grey define dividers and controls; and the old-way label colour marks failed evaluations. Clash Display is used for hero and section headings, General Sans for interface copy, while the documented spacing, border, and radius tokens shape the floating navigation, process cards, workspace, and buttons.
